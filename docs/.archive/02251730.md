## ~~P0-6 多条消息导出时 YAML 元数据解析失败~~

**现象：** 导出多条消息时报错：

```
导出失败: Pandoc conversion failed: ERROR: Error parsing YAML metadata at "/stdin"
(line 5, column 1): YAML parse exception at line 1, column 1,
while scanning an alias: did not find expected alphabetic or numeric character
```

单条消息通过复制按钮方式则正常（因为复制不经过 Pandoc 转换）。

**根因分析：**

`DEFAULT_CONFIG` 中 `userMessageTemplate` 和 `assistantMessageTemplate` 均以 `---` 起始（本意是 Markdown 水平分割线）：

```typescript
// types.ts — DEFAULT_CONFIG
documentPrefix: `---
title: {title}
date: {output_date}
---
`,
userMessageTemplate: `---
**用户：**
...`,
assistantMessageTemplate: `---
**助手：**
...`,
```

`assembleDocument()` 直接拼接后，`documentPrefix` 的 YAML front matter 终结符 `---` 和首条消息模板的 `---` 相邻，生成如下文本：

```markdown
---
title: 我的对话
date: 2026-02-25
---
---
**用户：**

Hello
```

Pandoc 将第 5 行的 `---` 解释为第二段 YAML 元数据块的开始，随后遇到 `**用户：**` 中的 `*` 字符被 YAML 解析器识别为 alias 标记，但 `*用户：**` 不是合法的 alias 名称，触发解析异常。

**建议：**

1. 在 `assembleDocument()` 中，确保 `documentPrefix` 末尾与首条消息模板之间插入至少一个空行 + 非 `---` 内容，打破 Pandoc 的 YAML 块连续检测。

## ~~P1-10 油猴脚本无 WASM 文件缓存机制~~

`userscript.ts` 的 `loadPandocWasm()` 每次页面加载均从 CDN 重新下载 pandoc.wasm（约 58 MB），无任何缓存机制：

```typescript
// userscript.ts
async function loadPandocWasm(): Promise<void> {
  const config = await loadConfig(gmStorage);
  const urls = config.cdnUrls;

  for (const url of urls) {
    try {
      showToast({ message: '正在下载 Pandoc WASM…', level: 'info', duration: 2000 });
      const wasmBytes = await fetchWasm(url);    // 每次全量下载
      await initPandoc(wasmBytes, new PandocWorker());
      ...
    }
  }
}
```

**后果：**

- 每次刷新页面或打开新对话页都需要重新下载 58 MB 文件，严重影响首次可用时间。
- 在网络较差的环境（如移动热点）中可能导致加载超时失败。
- CDN 流量浪费。

**建议：**

1. 首次下载后将 WASM 字节缓存到 IndexedDB（`GM_getValue` / `GM_setValue` 对大型二进制不理想，且有配额限制）。
2. 使用 WASM URL 或内容 SHA1 作为缓存键，以便在 CDN 版本更新时自动失效。
3. 加载流程改为：检查 IndexedDB 缓存 → 命中则直接使用 → 未命中则下载并存入缓存。
4. 可考虑在设置面板提供"清除 WASM 缓存"按钮供用户手动重置。

## ~~P2-11 点击面板外部区域应隐藏面板~~

`panel.ts` 当前仅支持通过关闭按钮或 `togglePanel()` 隐藏面板，未实现点击面板外部区域自动关闭。对于浮动面板，这是常见的交互预期。

```typescript
// panel.ts — 当前无 click-outside 处理
export function hidePanel(): void {
  if (panelEl) {
    panelEl.classList.add('gmd-panel--hidden');
    isVisible = false;
  }
}
```

**建议：**

在 `createPanel()` 中注册 `document.addEventListener('mousedown', handler)`，判断 `event.target` 是否在 `.gmd-panel` 内部：

```typescript
document.addEventListener('mousedown', (e) => {
  if (panelEl && isVisible && !panelEl.contains(e.target as Node)) {
    hidePanel();
  }
});
```

需注意排除以下场景：
- 点击触发面板显示的按钮本身（否则 show 和 hide 都在同一次 click 中触发，导致闪烁）。
- 拖拽操作开始于面板内部但结束于外部时，不应触发关闭。
- toast 弹出时点击 toast 本身不应关闭面板（如果 toast 设计为全局挂载）。

## ~~P2-12 模板管理 UI：用点击选中替代 Star 图标~~

当前模板管理列表中，通过一个 Star 图标按钮设置默认模板：

```typescript
// panel-settings.ts — renderTemplateList
if (tpl.id !== config.selectedTemplateId) {
  const starBtn = createIconButton({
    icon: ICON_STAR,
    title: '设为默认',
    variant: 'standard',
    onClick: async () => { ... },
  });
  row.appendChild(starBtn);
}
```

**需求：**

1. 移除 Star 图标按钮。
2. 整行 `tpl-row` 可直接点击以选择该模板。
3. 被选中的模板行通过前景色/背景色变化来明确标识（而非仅加粗），例如：

```css
.gmd-settings__tpl-row--selected {
  background: var(--gmd-primary-container);
  color: var(--gmd-on-primary-container);
}
.gmd-settings__tpl-row--selected .gmd-settings__tpl-name {
  color: var(--gmd-on-primary-container);
  font-weight: var(--gmd-font-weight-bold);
}
```

**好处：** 交互更直观，减少视觉元素，触控更友好（面板空间紧凑，图标按钮偏小）。

## ~~P2-13 关于页 Pandoc 引擎状态指示点未与文本垂直居中~~

`panel-about.css` 中 `.gmd-about__value--ok::before` 和 `.gmd-about__value--warn::before` 使用 `content: '●'`（`font-size: 10px`），但父级 `.gmd-about__row` 使用 `align-items: baseline`，导致小号圆点的基线与正文文字（`var(--gmd-font-size-md)`）的基线不一致，视觉上圆点偏低。

```css
/* panel-about.css */
.gmd-about__value--ok::before {
  content: '●';
  margin-right: var(--gmd-space-xs);
  font-size: 10px;       /* 与父级 font-size 不同，baseline 错位 */
}
```

**建议：** 使用 `vertical-align: middle` 或改为 `display: inline-flex; align-items: center` 方案：

```css
.gmd-about__value--ok::before,
.gmd-about__value--warn::before {
  content: '●';
  margin-right: var(--gmd-space-xs);
  font-size: 8px;
  vertical-align: middle;
}
```

或将圆点改为 inline SVG / `width + height + border-radius` 的圆形元素以获得更精确的控制。
